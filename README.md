# 🚗 Electric Vehicle (EV) Market Size Analysis (2010–2030)

![ev](https://github.com/user-attachments/assets/4fa7fd62-0ade-4ba8-a6a7-3118d2eb192d)


A data-driven project that analyzes global Electric Vehicle (EV) adoption trends, forecasts future sales and market revenue using ARIMA, and visualizes multi-scenario insights through a Tableau dashboard.


## 📘 Overview

This project explores historical EV market data (2010–2024) to:
- Understand global growth patterns
- Forecast sales and market size up to 2030
- Estimate revenue under different pricing scenarios
- Identify top-growing regions
- Visualize insights in an interactive Tableau dashboard

---

## 🧠 Objectives

1. Perform Exploratory Data Analysis (EDA) on real-world EV datasets  
2. Build a **time-series forecasting model (ARIMA)** to predict EV unit sales  
3. Simulate **revenue projections** under low, base, and high Average Selling Price (ASP) scenarios  
4. Design a **Streamlit dashboard** to communicate results clearly
